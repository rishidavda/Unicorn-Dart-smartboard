Venue branding assets (from thewinchestersc.co.uk).

  logo.png             THE WINCHESTER wordmark on one line, white, for dark
                       screens. This is the one in use. Our gold DARTS line
                       sits beneath it.
  logo-full-dark.png   The complete house lockup - wordmark plus
                       SNOOKER - POOL - BAR with the strapline lifted to
                       cream so it reads on the dark background. To use this
                       instead, rename it to logo.png.
  icon.png             The house mark, used as the browser tab icon.

Note: in the original artwork "THE" is set vertically and runs the full
height of the logo, so the strapline cannot be cropped away without
slicing it. Both files above keep it whole.

To use a different logo, drop in logo.svg or logo.png. Wide images are
treated as a wordmark and shown whole with the tagline beneath; squarish
ones sit beside the venue name. Refresh the screens after changing a file.
